# paper-implementations

My learning repo: implementations of ML papers from scratch, written to understand how they actually work. Code favours readability and comments over performance.

## Papers

| Paper | Folder | What's in it |
|---|---|---|
| [Attention Is All You Need](https://arxiv.org/abs/1706.03762) (Vaswani et al., 2017) | [attention-is-all-you-need/](attention-is-all-you-need/) | Encoder-decoder Transformer in PyTorch, English → Italian translation training, greedy decoding, attention visualization, plus KV cache and grouped-query attention |

Each folder has its own README with how to run it and notes.
